# 0.3.4 精简版功能对照

只保留 12 项功能。“实现”表示存在真实宿主操作，不代表所有图像格式与文档结构均已回归。

## 业务命令

| 界面按钮 | 命令 | 实现 | 范围 / 差异 |
|---|---|---|---|
| 置入文件 | `place` | 已实现 | 原生多选文件，按画板原点顺序错位摆放 |
| 定位路径 | `reveal` | 已实现 | 资源管理器定位并选中源文件，再把窗口置前；路径经临时文件传递（`app.system` 不能承载中文/UNC 命令串），依赖 `scripts/reveal.ps1`，失败逐级回退到 `explorer /select` 与仅打开文件夹；嵌入对象无源文件时报错 |
| 重新链接 | `relink` | 已实现 | 当前选区所有链接指向同一个替换文件 |
| 更新所在文件夹 | `relinkFolder` | 已实现 | 按相同文件名匹配，只在文件存在时重链 |
| 更新 PDF 页码 | `updatePdfPage` | 已实现 | PDF/兼容 AI；支持 6 种置入边界；临时改偏好后恢复 |
| 嵌入链接对象 | `embed` | 已实现 | Illustrator 原生 embed |
| 用 Illustrator 编辑 | `editAI` | 已实现 | 在宿主中打开选中链接的源文件 |
| 用 Photoshop 编辑 | `editPS` | 已实现发送端 | 需要本机 Photoshop；异步 BridgeTalk，不确认 PS 已打开 |
| 取消缩放 | `resetScale` | 已实现 | 以源文件密度归一化，保留中心与镜像 |
| 取消旋转 | `resetRotation` | 已实现 | 归一化到 0°，坐标系已按宿主 Y 轴约定换算 |
| 恢复原始变换 | `resetTransform` | 部分语义 | 归一化缩放与旋转，不能恢复历史摆放位置 |
| 指定缩放及角度 | `setTransform` | 已实现 | 设定目标值而非叠加；剪切或奇异矩阵拒绝执行 |

## 内部命令

| 命令 | 用途 |
|---|---|
| `ping` | 返回版本与宿主版本，兼作连接探针 |
| `scan` | 完整链接诊断：逐项读取图像头、矩阵、图层与画板，返回 rows；仅诊断用，两个面板刷新都不再调用 |
| `summary` | 轻量状态：仅文档名与链接/丢失/选中计数，不读文件、不算矩阵；原生面板状态行使用 |

## 界面行为

| 场景 | 表现 |
|---|---|
| 操作成功 | 底部轻提示，3 秒自动消失，不弹结果面板 |
| 部分失败 / 报错 | 弹出结果面板，列出逐条原因；右上角关闭 |
| 需要参数 | 面板内表单（页码与置入边界、目标缩放与角度），校验不过就地提示 |
| 需要确认 | 面板内确认框（嵌入、三种变换恢复） |
| 后台刷新 | 静默执行，不弹遮罩、不禁用按钮（避免首次点击被遮罩吞掉） |
| 连接失败 | 顶部红条提示；离线预览时按钮整体禁用 |

## 本版移除

栅格化（选择/每个/图层/画板/非本机/剪切组）、150 PPI 降采样、PNG 链接导出、JPEG 压缩副本、图像描摹、填充转轮廓描边、矩形出血框、链接文字标签、网格排列、复制到闭合刀线、重命名链接副本、复制链接以修改、路径替换、前后缀替换、智能选择全部筛器、文件列表与搜索、本地设置存储、顶部标题区/文档信息条/底部状态栏/能力边界说明。

这些代码已从 `jsx/core.jsx`、`jsx/artwork.jsx`、`js/panel.js`、`index.html`、`LinkForge.jsx` 中删除，不是仅隐藏按钮；`css/panel.css` 中对应的 89 条选择器也已清理。需要时从 `.workbuddy/backup-0.1.4/` 取回。

## 验收建议

正式生产前至少覆盖：CMYK TIFF 链接、带 ICC 的 JPEG、二页 PDF 切页、中文长路径与含空格路径、网络共享断开、锁定/隐藏图层、多选批量重链、镜像对象取消缩放、剪切对象拒绝执行、撤销后再操作。每种文档保留原件，验收包含保存、关闭、重新打开后的外链路径与对象结构。
